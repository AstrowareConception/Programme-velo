# Trophées et récompenses

La galerie **Plus → Badges** contient 83 trophées. Les six nouveaux objectifs reconnaissent aussi les séances déjà enregistrées.

| Trophée | Condition |
| --- | --- |
| 🌱 Trois rendez-vous | Du vélo enregistré pendant 3 jours consécutifs |
| 🌟 Sept jours en selle | Du vélo enregistré pendant 7 jours consécutifs |
| 🌿 Routine naissante | 2 semaines consécutives avec du vélo au moins 3 jours par semaine |
| 🗓️ Un mois de rendez-vous | 4 semaines consécutives avec du vélo au moins 3 jours par semaine |
| 💎 Le rythme s’installe | 8 semaines consécutives avec du vélo au moins 3 jours par semaine |
| 🏆 Fidèle au rendez-vous | 12 semaines consécutives avec du vélo au moins 3 jours par semaine |

Les semaines vont du lundi au dimanche et laissent des jours de repos. Une activité facile, une micro-séance ou une portion enregistrée compte, si sa durée est positive ; plusieurs séances le même jour ne comptent que pour un jour. Les dates futures ne comptent pas. Les seuils n’exigent aucune intensité et n’ajoutent pas d’XP.

La meilleure série de ton historique détermine le déblocage : une pause ultérieure ne retire pas le trophée. Corriger, supprimer ou importer des séances recalcule les progrès depuis les données présentes. Les jours sont ceux du calendrier local de l’appareil ; un changement de fuseau peut modifier leur classement.

## Savourer une récompense

Après l’enregistrement, une notification dorée affiche les nouveaux trophées ensemble. Elle attend la fin d’une séance, d’un bilan ou d’un formulaire protégé. **Voir mes trophées** ouvre la galerie ; **Continuer** ou la croix ferme la notification. Elle reste visible jusqu’à ton action.

Le petit son utilise **Plus → Ton cockpit → Sons de changement de segment** et le volume des alertes. Les vibrations suivent leur réglage habituel. Le navigateur peut exiger une interaction préalable pour autoriser le son ; la récompense visuelle reste disponible. Le réglage système de réduction des animations est respecté.

Chaque appareil mémorise les trophées déjà annoncés. Les anciens trophées ne rejouent pas toutes leurs notifications lors de cette mise à jour ; les nouveaux trophées de régularité acquis auparavant font l’objet d’une seule annonce groupée. Un nouveau trophée peut être annoncé sur chacun de tes appareils après synchronisation. Les préférences d’annonce restent locales ; le JSON les conserve. Une suppression puis un nouveau déblocage ne rejoue pas une annonce déjà mémorisée.
